# 避风塘 Harbor Bar

基于 SillyTavern 官方 Chat Top Bar 的二改分支（AGPLv3）。

顶栏原搜索框改建为「浮窗停车场」：满屏漂的插件浮标自动入库，
在栏内变成一排小胶囊，点击功能与原浮窗完全一致。

## 泊位

- 🔍 搜索：点开展开输入框，再点收起并清空高亮
- 🎞️ ARB（Arrebol D 小红霞浮标）
- 🐚 IPE（小海螺快捷入口）

未安装的插件，对应泊位自动不出现。
新浮标想入库：在 index.js 顶部 `HARBOR_REGISTRY` 加一行选择器即可。

## 安装

扩展安装器直接装本 zip / 本仓库地址。与官方 Chat Top Bar 互斥，装前请先卸载官方版。
auto_update 已关闭，不会被官方更新覆盖；新版本需要在扩展管理里手动点更新。

## 美化不适配自救指南

避风塘会自动躲开大部分美化的遮挡：美化把聊天区铺满全屏、把顶栏加高、
或者在顶栏上挂了能点到的花边时，它会自己浮起来，贴到不被挡住的位置；
底色也会自动跟随美化的顶栏（顶栏透明它就透明）。

自动适配管不到的情况，按下面顺序排查：

**0. 先更新到最新版。** 很多不适配在新版里已经修好了。

**1. 整个聊天区掉到屏幕下半截** → 美化导入时顺手打开了「视觉小说模式」。
到「用户设置」里把「视觉小说模式」关掉即可。这是酒馆自带的功能，不是避风塘的问题。

**2. 避风塘看不见（被顶栏的装饰图盖住）** → 在「用户设置 → 自定义 CSS」
**最末尾**另起一行加上：

```css
#extensionTopBar { margin-top: 22px !important; }
```

把避风塘往下推出装饰图的范围。还被挡着就把数字改大，离得太远就改小。
原因：很多美化给顶栏挂的装饰图写了 `pointer-events: none`（点击可以穿过去），
避风塘检测不到这种「只挡视线、不挡手指」的遮挡。

**3. 避风塘浮起来了，但位置差一点** → 同样在自定义 CSS 最末尾加：

```css
:root { --harbor-offset-y: -10px; }
```

负数往上、正数往下。只对浮起状态的避风塘生效。

**4. 美化作者主动隐藏了避风塘** → 在美化 CSS 里搜 `extensionTopBar`，
看有没有 `opacity: 0` 或 `display: none` 之类的写法。有的作者会留一个开关变量
（例如 `--topbar透明度: 0`），改成 `1` 就能显示出来。

以上都不管用：截图 + 美化 JSON 文件一起反馈。
